# Every runtime, migration, ML, and test dependency in one file.
#
# Replaces the previous requirements/base.txt + dev.txt + embeddings.txt
# split. `sentence-transformers` (and therefore torch) is now included
# rather than opt-in: the app cannot embed or rerank without it, so a
# "docker compose up and it works" setup has to have it. Consequences to
# know about:
#   - the image is large (torch is ~2.5GB of it)
#   - BAAI/bge-m3 (~2.3GB) downloads on FIRST USE, not at build time, and
#     is cached in a Docker volume (see docker-compose.yml) so it isn't
#     re-downloaded every time the container is recreated
#
# Pinned exactly, deliberately: an unpinned rebuild months later is a
# different application.
